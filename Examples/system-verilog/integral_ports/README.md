# Integral variable ports

`integral_ports.sv` exercises scalar/vector two-state inputs, signed inputs,
predefined `int`/`integer` ports, a two-state output assignment, sign extension,
and signed comparison. `startup.sv` checks unconnected two-state startup and
x/z conversion on output assignment. Both envelopes are generated by the
ordinary extractor.

`proof.lean` checks the complete hand-transcribed design against the real
envelope before proving input conversion precedes expression evaluation,
conversion idempotence, and width-parametric unconnected startup rules.

The ordinary differential table includes known and x/z inputs, as well as
an absent-stimulus cycle that must retain the preceding converted value:

```
python3 harness/sv/diff_test.py --case integral_ports_directed --sim iverilog
```

All connected-input rows agree with Icarus. The separate unconnected startup
fixture differs: Icarus 13.0 (development build `dad78d525`) leaves unconnected
two-state inputs z, while independent simulation and the model initialize
them to zero. That startup result is recorded as a divergence, not agreement.

`initialized.sv` checks input defaults and a two-state output initializer.
Their expressions survive extraction and run through declaration initialization;
invalid output-net port initializers still refuse rather than being dropped.
